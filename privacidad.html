HILEN Sistema

Política de Privacidad

Última actualización: 29 de agosto de 2026

HILEN Sistema es una aplicación de gestión utilizada para organizar información del negocio, como ventas, clientes, abonos, movimientos de caja, productos y respaldos.

1. Información que utiliza la aplicación

HILEN Sistema procesa únicamente la información que el usuario registra dentro de la aplicación y la información técnica necesaria para iniciar sesión, sincronizar datos y crear respaldos.

2. Uso de Google

Cuando el usuario decide conectar su cuenta de Google, HILEN Sistema solicita autorización para crear y actualizar archivos de respaldo en Google Drive y hojas de cálculo en Google Sheets. El acceso se utiliza únicamente para las funciones de respaldo y sincronización solicitadas por el usuario.

3. Almacenamiento de datos

Los datos principales de HILEN Sistema pueden almacenarse en Firebase. Los respaldos externos, cuando el usuario los habilita, pueden almacenarse en su propia cuenta de Google Drive y Google Sheets.

4. Compartición de información

HILEN Sistema no vende la información del usuario ni la utiliza con fines publicitarios. La información no se comparte con terceros salvo los servicios tecnológicos necesarios para operar las funciones que el propio usuario habilita.

5. Control del usuario

El usuario puede desconectar Google desde HILEN Sistema y también puede revocar los permisos concedidos desde la configuración de seguridad de su cuenta de Google.

6. Seguridad

Se aplican medidas razonables para proteger la información y limitar el acceso a los datos a las funciones necesarias de la aplicación.

7. Cambios a esta política

Esta política puede actualizarse cuando cambien las funciones de HILEN Sistema o los servicios utilizados para almacenar y respaldar información.

8. Contacto

Para preguntas relacionadas con privacidad o el uso de la información, utiliza el correo de soporte indicado en la pantalla de consentimiento de HILEN Sistema.
